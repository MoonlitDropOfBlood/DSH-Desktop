FEATURES

主要功能

把 DSH 装进一个原生桌面应用，保留完整能力，补上桌面该有的体验。

沉浸式桌面窗口

无边框（frameless）窗口，DSH Web UI 占满整个屏幕；最小化 / 最大化 / 关闭按钮融入右上角悬浮控制条，不遮挡任何 DSH 内容；插件失效时自动降级为内置备用控制条，窗口永远可关。

系统托盘

DeepSeek 鲸鱼托盘图标，右键「打开 / 退出」。开启「常驻通知栏」后，关闭窗口最小化到托盘，后台持续运行。

保持最新

内置「核心」设置页显示 DSH 版本、一键检查更新，支持自动更新；更新先停核心再安装再重启，全程带进度条，安全无崩溃。

任务通知

主任务完成、失败或需要确认时发送桌面通知——严格限定主会话，子任务（subagent）不打扰；窗口聚焦时不弹；可选「阻止休眠」，任务运行期间防止系统睡眠。

内置插件市场

开箱即用的插件市场（dshmarket），目标机器零下载：浏览、安装、管理 DSH 插件全在应用内完成；壳自动接管插件重启语义，杜绝野核心残留。

插件故障自愈v1.5.0

插件加载失败导致核心无法启动时，壳自动识别出问题的第三方插件（系统插件排查在外）、自动卸载并重启，恢复后面板明确告知卸载了哪个插件——DSH 被玩坏也能自己站起来。

继承终端 Profile

自动加载终端里的环境变量（PATH 等）传给 DSH，MCP 服务等外部进程能正常找到可执行文件；macOS 从 Finder 启动时没有终端环境变量，此开关默认开启。

HOW IT WORKS

工作原理

启动一次，你拥有的是一套会自动保持最新的完整 DSH。

1

定位 DSH：应用托管目录 → node_modules → npm _npx 缓存（取最新完整安装）。

2

自动安装：没有则用内置 pnpm 安装 @deepseek-ai/dsh@latest（registry 探测 + 失败重试/换镜像 + 实时进度条与已下载大小）。

3

端口预检：被占用则弹出「换端口并重试」面板（端口持久化记忆）。

4

嵌入启动：DSH 核心以内置独立 Node 运行（Windows 无弹窗、零依赖），桌面插件嵌入窗口控制条 / 设置页 / 更新徽章，URL 加载进 frameless 窗口。

5

持续守护：失败回到启动页（可复制错误）；退出时清理整棵进程树；崩溃一键重启；插件导致的启动失败自动卸载罪魁并自愈；更新先停核心再安装再重启，安全无崩溃。

可选环境变量

变量作用
DSH_DESKTOP_PORT指定端口（默认 3080）
DSH_DESKTOP_HOME覆盖 DSH_HOME（默认 ~/.dsh）
DSH_DESKTOP_NPM_REGISTRYnpm 镜像（默认 npmmirror，国内网络需要）
DSH_DESKTOP_NPM_CACHEnpm 缓存目录
DSH_DESKTOP_SPECDSH npm 规格（默认 @deepseek-ai/dsh@latest）
