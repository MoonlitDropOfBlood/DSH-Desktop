FEATURES

主要功能

把 DSH 装进一个原生桌面应用，保留完整能力，补上桌面该有的体验。

沉浸式桌面窗口

无边框（frameless）窗口，DSH Web UI 占满整个屏幕；最小化 / 最大化 / 关闭按钮融入右上角悬浮控制条，不遮挡任何 DSH 内容；插件失效时自动降级为内置备用控制条，窗口永远可关。

系统托盘

DeepSeek 鲸鱼托盘图标，右键「打开 / 退出」。开启「常驻通知栏」后，关闭窗口最小化到托盘，后台持续运行。

保持最新

内置「核心」设置页显示 DSH 版本、一键检查更新，支持自动更新；更新先停核心再安装再重启，全程带进度条，安全无崩溃。

任务通知

主任务完成、失败或需要确认时发送桌面通知——严格限定主会话，子任务（subagent）不打扰；窗口聚焦时不弹；可选「阻止休眠」，任务运行期间防止系统睡眠。

内置插件市场

开箱即用的插件市场（dshmarket），目标机器零下载：浏览、安装、管理 DSH 插件全在应用内完成；壳自动接管插件重启语义，杜绝野核心残留。

插件故障自愈v1.5.0

插件加载失败导致核心无法启动时，壳自动识别出问题的第三方插件（系统插件排查在外）、自动卸载并重启，恢复后面板明确告知卸载了哪个插件——DSH 被玩坏也能自己站起来。

继承终端 Profile

自动加载终端里的环境变量（PATH 等）传给 DSH，MCP 服务等外部进程能正常找到可执行文件；macOS 从 Finder 启动时没有终端环境变量，此开关默认开启。

HOW IT WORKS

工作原理

启动一次，你拥有的是一套会自动保持最新的完整 DSH。

1

定位 DSH：应用托管目录 → node_modules → npm _npx 缓存（取最新完整安装）。

2

自动安装：没有则用内置 pnpm 安装 @deepseek-ai/dsh@latest（registry 探测 + 失败重试/换镜像 + 实时进度条与已下载大小）。

3

端口预检：被占用则弹出「换端口并重试」面板（端口持久化记忆）。

4

嵌入启动：DSH 核心以内置独立 Node 运行（Windows 无弹窗、零依赖），桌面插件嵌入窗口控制条 / 设置页 / 更新徽章，URL 加载进 frameless 窗口。

5

持续守护：失败回到启动页（可复制错误）；退出时清理整棵进程树；崩溃一键重启；插件导致的启动失败自动卸载罪魁并自愈；更新先停核心再安装再重启，安全无崩溃。

插件扩展点

DSH 插件可以调用桌面壳的能力：桌面通知、托盘右键菜单、插件设置、窗口/任务栏控制与壳事件订阅。

1

RPC 桥：壳在本地起一条 HTTP JSON-RPC 通道，只绑 127.0.0.1，每次启动随机端口 + 随机令牌（经环境变量只传给 DSH 进程，网页与无关本地进程无法调用）。

2

Host 半部接入（运行在 DSH 进程内的插件）：从 process.env.DSH_DESKTOP_NOTIFY_PORT / DSH_DESKTOP_NOTIFY_TOKEN 读地址与令牌，POST http://127.0.0.1:<port>/ 并带 x-dsh-notify-token 头，body 为 { "method": "...", "params": { ... } }；响应 { ok: true, ... } 或 { ok: false, error }（ok:false = 旧壳无此方法，不必重试）。

3

Client 半部接入（运行在 DSH 页面里的插件）：桌面壳给页面注入 window.dshDesktop（普通浏览器直接访问时不存在，用前判空）——windowAction(action, params)、pluginSettingsGet(plugin, key) / pluginSettingsSet(plugin, key, value)、onShellEvent(cb)。

4

设置页：插件需要设置 UI 时，用核心 Cordis 的 settings.section 槽挂整页（ctx.slots.register({ name: "settings.section", id, order, label }, Component)，桌面版设置区自身就这么挂的），持久化用下面的插件设置 KV。

方法作用
bridge.register注册插件（notify/tray/window.* 前置；settings.* 不要求）。可带 eventPort——插件自起的 127.0.0.1 HTTP 端口，壳把托盘点击与订阅事件回投到它（同一令牌）；events 可订阅 window.visibility、core.lifecycle
notify.show桌面通知。kind=done/error/approval 有默认文案；force:true 绕过「窗口聚焦时不弹」抑制；受设置「任务通知」总开关约束
tray.setMenu贡献托盘右键菜单分区（items: [{id, label, enabled?}]，每插件 ≤10 项），点击回投 {event:"tray.click", id}
settings.get / settings.set按插件命名空间的设置 KV（值限 string/number/boolean，null 删除该 key），持久化在壳的设置文件里
window.*窗口/任务栏能力：progress（任务栏进度，-1 清除 / 0..1 确定 / >1 不确定）、flash（闪烁，窗口获焦自动停）、badge / overlay（角标）、alwaysOnTop、show / hide / minimize
float.window.*插件浮窗（桌面宠物、迷你状态条）：创建小型透明置顶悬浮窗——永不抢焦点、不进任务栏；状态下行推送、页面点击回投，核心重启/退出自动清理，设置「允许插件浮窗」可整体关闭

完整协议（参数校验、生命周期清理、安全模型与最小代码示例）见仓库 README 的「插件扩展点」一节。
